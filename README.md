# Novumism

**Novumism** is Ryan Miller’s series of religious philosophy: *Novum Carta* (Book I), *The Civilizational Man* (Book II), and *The Great Orchestration* (Book III). This repository is the public site at [novumism.com](https://novumism.com) — free PDFs, covers, and open markdown for readers and for LLMs that credit the author.

The site is static HTML and CSS (no build step). Book links and covers are set in the `BOOK_LINKS` block near the top of `index.html`. Manuscript sources live in their own repos; this one is the storefront and the scrapable text for the series.
